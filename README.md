# AI Customer Support Agent with RAG Knowledge Base

## Overview

This project is an AI-powered Customer Support Agent built with n8n, OpenAI, and RAG (Retrieval-Augmented Generation).

The workflow allows users to send customer support questions through a chat interface. The AI Agent searches a knowledge base for relevant information and generates helpful responses.

## Features

- AI Customer Support Agent
- RAG-based knowledge retrieval
- OpenAI Chat Model
- OpenAI Embeddings
- Simple Vector Store
- Chat Trigger integration
- Knowledge base search

## How It Works

1. A customer sends a message through the chat.
2. The AI Agent receives the question.
3. Relevant information is retrieved from the knowledge base.
4. The AI generates a helpful response based on the retrieved information.

## Technologies Used

- n8n
- OpenAI
- RAG
- Vector Database
- AI Agents

## Workflow

The repository includes the exported n8n workflow JSON file. You can import it directly into n8n and configure your own credentials.

## Use Cases

This workflow can be adapted for:

- Customer support automation
- FAQ systems
- Product information assistants
- Internal knowledge base assistants
